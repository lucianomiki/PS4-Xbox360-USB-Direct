# PS4 Xbox 360 USB Direct v0.2.0

First public release of the wired Xbox 360 USB adaptation
based on Control4Free 1.2.0.

## Tested

- PS4 firmware 13.02
- Wired Xbox 360 controller
- GoldHEN manual payload launch
- SpiderHeck and Cuphead
- Stable frame rates and independent players
- USB disconnection and reconnection
- PS4 user assignment retained after reconnection

## Installation

Download `control4free-usb-v0_2.elf`, copy it to
`/data/payloads/` using FTP and launch it once from
GoldHEN PayLoader LaunchPad.

Do not enable the original Control4Free service or
conflicting controller plugins at the same time.

Other firmware and controller models are untested.
